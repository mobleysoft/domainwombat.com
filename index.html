Domain Availability Checker

Checks the authoritative registry directly. No registrar search box in the loop.
Why this exists: registrar search boxes (GoDaddy and others) have a documented history of "domain front-running" — searching for a name signals interest, and the domain gets registered before you can check out. This tool queries the domain registry's own RDAP server (the modern, standardized replacement for WHOIS) directly, the same source of truth any registrar would use, without going through a commercial search interface built to capture interest signals. It reduces exposure to the well-documented search-box-sniping pattern — it isn't an absolute guarantee against every possible bad actor, and only works for TLDs whose registry has deployed RDAP.

Coverage note: RDAP is deployed by most registries but not all. As of this build, .com, .cc, and .finance are supported directly; .io and .me are not yet in the IANA RDAP bootstrap registry and will report "not available" rather than a guess. Full TLD map: rdap_tld_map.json (source: IANA RDAP bootstrap). "Check all TLDs" runs the same real per-registry query against a shortlist of 12 common commercial TLDs (com/net/org/cc/dev/app/ai/biz/info/xyz/finance/tech) - not the full 1200-TLD map, since most of those registries either aren't relevant to a new venture name or block direct browser RDAP queries entirely.
